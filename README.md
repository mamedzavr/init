# init

42 **init** project: answers and scripts for system administration, networking, and shell exercises.

## Layout

```
network/   # networking questions (01–…)
system/    # system administration questions
scripts/   # shell scripting exercises
init.en.pdf
```

Each numbered file under `network/`, `system/`, and `scripts/` corresponds to a subject question from the PDF brief.

## Notes

- Scripts are meant to be run in a Unix-like environment matching the 42 subject constraints.
- Treat this as coursework reference material, not a deployable app.
